# 03 — Plan

## Inputs

- Intake brief and scout evidence.
- Relevant stable references from `PROJECT_CONTEXT.md` and `docs/references/`.

## Process

For non-trivial work, write a short, reviewable plan with exact files, ordered actions, meaningful checks, and acceptance evidence. Keep task scope small. For parallel workers, assign disjoint files and bounded context; the lead owns integration and Git writes.

## Outputs

- A short plan suitable for review before implementation.
- A disjoint file/role assignment only when parallel work has a distinct benefit.
