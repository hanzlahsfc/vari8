# 01 — Intake

## Inputs

- Current user request and higher-priority instructions.
- `AGENTS.md` and the relevant product boundary in `PROJECT_CONTEXT.md`.

## Process

Identify the requested outcome, scope, current authority, and any constraints. Preserve user authorization and do not infer backend integration, Git publication, or external actions from ordinary product work.

## Outputs

- A one-paragraph task brief with observable completion criteria.
- The next stage and the exact files or facts it needs.
