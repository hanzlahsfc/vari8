# 04 — Build

## Inputs

- Approved task scope and plan.
- The exact files and Layer 3 references assigned to this implementation.

## Process

Make the smallest complete change. Follow the project stack and preserve the existing UI style unless the user directs otherwise. Do not add credentials or real client data. Do not use a hidden control as security. Keep per-run notes out of tracked references.

## Outputs

- The completed scoped change in its owned files.
- A concise list of changed paths and any implementation decisions needed for validation.
