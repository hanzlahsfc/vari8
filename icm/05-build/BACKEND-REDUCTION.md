## 6. Method and limits

- LOC: non-blank lines, tracked code files, per directory. `frontend/`, `tests/`, `icm/`, `docs/`, `spec/` excluded from the prod total.
- Import graph: regex parser for `import`, `export ... from`, and `import()`, resolving `@/` and relative paths. Root files included (`auth.ts`). Name-level matching. `import *` counted as using every name. Not a TypeScript compiler.
- Dead exports: 207 names with no importer; 18 with zero references anywhere in code (word count).
- ts-prune not run. The re-derived figures use the TypeScript compiler API (`ts-facts.cjs`) against the worktree install (`npm ci`), which supersedes the regex graph for the corrected findings.
- Duplicates: normalized 8-line windows, trivial lines dropped. 1,400 duplicate windows across 119 files. Cluster counts overlap, so they are not summed.
- Retry bodies: AST printer output per function, comments removed, hashed. The independent check used whitespace-normalised text, which groups two more bodies together (15 against 13). Constants read from the same file scope as each copy.
- Boundary helpers: statement spans of the named declarations in `lib/*boundary*.ts`. The independent check brace-matched from the declaration line, which reads `guard` about 20 lines smaller.
- Flag call sites: grep, 112 lines strict and 243 with the gate and classifier call sites.
- Items marked "est." or "estimate" are judgement, not measured. Expect about plus or minus 10% on F3 and F11.
- Raw data: `icm/05-build/evidence/AUD-REDUCTION-FIX/census.txt` and `ts-facts.txt` (both regenerated at f02a6d6), plus `/home/nexuslink/.hermes/cache/scratch/graph.json` (import graph, exports, per-file LOC) and `loc.json` from the first pass.
